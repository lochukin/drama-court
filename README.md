# Drama Court · 网球场外档案

把网球场上发生过的荒诞时刻，画成一组可悬浮查看的卡通人物，铺在一整块球场上。
按场地分为红土 / 硬地 / 草地三册。

## 现状

- 22 个人物资产（WebP，透明背景，统一六头身比例）
- 17 个事件，均带两条以上可点击出处
- 四套 UI 方案待定稿（`index.html#editorial|cinema|archive|sticker`）

## 目录

```
assets/      人物资产（webp）+ manifest.json
refs/        真人参考照片与头部裁剪（不入库）
index.html   UI 方案原型（四套主题，右下角可切换）
```

## 素材约定

- 背景必须是纯中灰 `#BEBEBE`，用 `keybg.py` 按色抠图
- 严禁任何 logo / 商标 / 文字 / 号码，生成时须显式禁止
- 统一六头身比例；着色为粗黑描边 + 扁平色块
- 真人参考只喂头部裁剪，避免把品牌标识一起抄进来

## 事件入库标准

1. 至少两条互相独立的可点击出处
2. 有具体的动作或冲突，不只是"某个习惯"
3. 同一个人物不超过 2 条
